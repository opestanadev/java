# Estudos de Java :coffee:

O intuito desse repositório é mostrar o meu progresso no aprendizado da linguagem Java, estou utilizando como base para o meu aprendizado o curso de Java do Prof. Dr. Nélio Alves na Udemy.

Até o final do curso, espera-se que eu aprenda:

- Lógica de Programação (já aprendi anteriormente, estou apenas revendo alguns conceitos)
- Programação Orientada a Objetos
- Acesso a banco de dados
- Java EE - Mapeamento objeto-relacional com JPA/Hibernate
- Aprender a utilizar Spring Boot e MongoDB (banco de dados não-relacional)
- Desenvolver projetos utilizando a linguagem Java e as demais ferramentas que serão ensinadas no curso

Por questão de preferência, gosto de fazer anotações no caderno, para melhor fixação. Porém em alguns casos, deixarei uma ou outra anotação importante como comentário dentro do código.

Espero que esse repositório sirva para mostrar meu progresso para qualquer um que visitá-lo algum dia.
